# Permai Polyclinics Fortuna

Landing page for Permai Polyclinics Fortuna, a 24-hour walk-in clinic at Fortuna Commercial Centre, Mile 2.5, Jalan Penampang, 88200 Kota Kinabalu, Sabah.

Single-file static site (`index.html`) with a lazy-loaded hero video (`assets/video/`, WebM preferred, MP4 fallback) over an always-visible poster image (`assets/img/hero_poster.jpg`).
